# DevArena demo senaryoları

Bu Python dosyaları jüri demosunda **Mevcut Kodumu Denetle** akışına örnek girdi sağlamak için hazırlanmıştır. İçlerinde bilerek bırakılmış SSRF, SQL injection/gizli anahtar sızıntısı ve eşzamanlı bakiye güncelleme riskleri vardır. Gerçek servislerde veya gerçek sırlarla kullanılmazlar.

Arayüzdeki hızlı senaryo düğmesine basınca ilgili dosya doğrudan denetim kutusuna yüklenir. Bu klasör ana DevArena deposunun parçasıdır; projeyi klonladığınızda senaryolar da gelir.
